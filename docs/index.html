Local document assistant

Read the record. Cite the page.

Legal AI Hub is a Streamlit app for questions over contracts, policies, case files, and regulations. It retrieves the relevant passages, then asks a language model to answer with file and page citations. Documents and vector indexes stay on the machine that runs the app.

View the repository Run it locally

This site is the public project page. The assistant itself is a Python app and does not run in the browser. Answers are a research aid, not legal advice.

Six tools

Each tool uses the same sidebar: files already in data/, or a file you upload.

01

Contract Q&A

Questions over contract text, organized as rights, obligations, risks, and exceptions.

02

Policies Q&A

Questions over company and regulatory policy PDFs, with citations back to the source.

03

Contract Risk Analyzer

Flags risky clauses against a curated knowledge base, and can cross-check a contract you upload.

04

Litigation Support

Searches local case documents and live CourtListener opinions, then returns a structured answer.

05

Compliance Audit

Builds an audit report of gaps, discrepancies, outdated procedures, and an overall rating.

06

Regulations Search

Pulls live U.S. federal documents from regulations.gov, embeds them, and answers in one pass.

How an answer is produced

The same path is used by the document tools. Live search adds CourtListener or regulations.gov before that index step.

  1. Load and splitPDFs, text, and CSV rows are cut into overlapping chunks so a clause is not lost at a boundary.
  2. Index locallyChunks are embedded with all-MiniLM-L6-v2 and stored in Chroma on disk. An existing collection is reused.
  3. Retrieve and answerKeyword and semantic search pick the passages. Groq writes the answer from those passages only.

Run it locally

You need Python 3.11 or newer, a GROQ_API_KEY, and the documents you want to search. CourtListener and Apify keys are only required for the live search tools.

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run streamlit_app.py
